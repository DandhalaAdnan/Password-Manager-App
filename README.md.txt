# 🔐 Password Manager App
A simple and secure password manager built using **Kotlin**, **Jetpack Compose**, **Room**, and **AES encryption**.
This project was created as part of the **Mobile App Developer Internship Practical – MOBILEIIP02504**.

---

## 📱 Overview
This app allows users to securely store, manage, and update their account passwords.
The entire app is built using **Modern Android Development (MAD)** practices.

✅ Jetpack Compose
✅ MVVM + Clean Architecture
✅ Hilt Dependency Injection
✅ Room Local Database
✅ AES Encryption for password security
✅ Validation + Error handling
✅ Smooth UX with Bottom Sheets
✅ Light/Dark Mode Support

---

## 🚀 Features

### ✅ Core Features
- Add a new password
- View saved passwords
- Edit existing passwords
- Delete a password
- Show/Hide password in details
- Empty state UI when no data
- Smooth bottom-sheet interactions

### ✅ Security Features
- Strong AES encryption for storing passwords
- Passwords NEVER stored in plain text
- Secure key stored using EncryptedSharedPreferences
- No sensitive logs or debug output

### ✅ UI/UX
- Modern Compose UI
- Bottom sheets for Add/Edit & Details
- Clean spacing, typography & ripple interactions
- Error validations for all fields
- Simple and minimal design
